# AcademiIA
Crie o módulo de autenticação da AcademiAI em Next.js 15, TypeScript, TailwindCSS e Supabase, com cadastro, login, recuperação de senha, sessão persistente, proteção de rotas, perfil inicial automático, middleware, páginas responsivas (/login, /cadastro, /esqueci-senha, /dashboard) e SQL da tabela profiles, pronto para produção.
